tmux — tldr quick examples

Copy-pasteable examples for the 10 most common tmux 3.7 operations. Install via x eget x-cmd-build/tmux or grab the matching archive from Releases.

1. Start a new session

tmux new-session -s work -d    # detached, named 'work'
tmux ls                          # list sessions

2. Attach / detach

tmux attach -t work              # attach to existing session
Ctrl-b d                         # detach (default prefix)

3. Windows (tabs)

Ctrl-b c    # create new window
Ctrl-b ,    # rename current window
Ctrl-b n    # next window
Ctrl-b p    # previous window
Ctrl-b &    # kill current window

4. Panes (splits)

Ctrl-b %           # vertical split
Ctrl-b "           # horizontal split
Ctrl-b o           # cycle panes
Ctrl-b ;           # toggle last-active pane
Ctrl-b x           # kill current pane

5. Resize panes

Ctrl-b Up/Down/Left/Right   # 1-cell resize
Ctrl-b Alt-Up/Down/Left/Right  # 5-cell resize
Ctrl-b z                    # toggle zoom (full-screen pane)

6. Copy mode (scroll + copy)

Ctrl-b [            # enter copy mode (vim-like)
  q                  # quit copy mode
  /foo               # search forward for 'foo'
  ?foo               # search backward for 'foo'
  Space              # start selection
  Enter              # copy selection
Ctrl-b ]            # paste

7. Status line customization

# add to ~/.tmux.conf:
set -g status-right "%H:%M"
set -g status-bg black
set -g status-fg green

8. Reload config without restarting

tmux source-file ~/.tmux.conf
# or, inside tmux:  Ctrl-b :  then type  source-file ~/.tmux.conf

9. Remote pair-programming via SSH

ssh user@host -- tmux new-session -s pair -d   # start on remote
ssh user@host -- tmux attach -t pair            # attach (or share) session

10. Control mode (scripting)

tmux -C -S /tmp/ctl new-session -d -s bot 'sleep 3600'

See man tmux for the full reference (700+ lines). All upstream tmux 3.7 features work in this build: floating panes, sixel images (with --enable-sixel), run-shell argument expansion (#{1}…#{N}), and the new status-format-2 second status line.
